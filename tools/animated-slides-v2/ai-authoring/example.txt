Worked example of valid "Load from code" output — a 2-slide project.

Notice the element with id "headline" appears on BOTH slides with different
x/y/content. Because the id is reused, Animated Slides v2 treats it as the
SAME element continuing across the slide change and animates it from its
slide-1 position/state to its slide-2 position/state, instead of fading one
out and a new one in. That's the "linking" mechanic — reuse an id on purpose
whenever something should visibly move/morph between slides; give elements
distinct ids whenever they should just fade out/in independently.

This is exactly the two-line block the tool's "Load from code" parser looks
for (see importFromCode() in index.html) — paste exactly this shape, nothing
more is required around it.
